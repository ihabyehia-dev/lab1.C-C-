# C/C++ Lab - Sensor Analysis and Memory Practice

Course exercise using C++ source and header files. It explores structures, dynamic memory, and processing integer sensor readings from a file.

## Repository files
- `main.cpp` - attempts to load readings and print summary statistics
- `dma.cpp` and `dma.h` - dynamic memory support
- `CC.cpp`, `CC.h` - a separate card-class exercise
- `reflect.txt` - reflection notes

## Status / missing dependencies
The current `main.cpp` includes `sensorAnalysis.h` and `cstr.h` and expects an input file named `sensor_readings.txt`. Those dependencies are **not present** at the repository root, so this is not yet a standalone compilable sensor-analysis program.

This repository contains material from more than one exercise. The original source is preserved for coursework reference. Add the corresponding source/header files and sample input before treating it as a complete application.
